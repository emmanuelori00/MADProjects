For the bullseye, I drew three circles at the same center using amber, blue, and red.
The radii were r, r * 0.65, and r * 0.3, so each smaller circle fits inside the previous one.

The rectangle hat shows on top when I draw it after the face.
When I move that draw call before the face, most of the hat disappears because the face is filled in over it.
The part outside the face still shows, so changing the draw order is what fixes it.
